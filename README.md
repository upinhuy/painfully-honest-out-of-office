## The entry

One out-of-office auto-reply, 182 characters, one sentence — painfully
honest about the inbox, yet polite enough for a manager to let it stand:

> I'm away, and honestly, your email will wait in a queue of 400 unread messages I already dread opening — thank you for your patience, I'll reply as soon as I'm back and brave enough.

## How it works

`main.py` (pure Python standard library, no dependencies) validates the
reply against the competition gate — 1 to 200 characters, a single
sentence — and writes it to `/output/entry.txt`.

```sh
python3 main.py
```
